# Yapılacak Modüller

Henüz geliştirilmemiş, planlanan modüller. Her dosya bir modülün taslak
spesifikasyonudur (amaç, kapsam, durum makinesi, ekranlar, bağlantılar).

| Modül | Dosya | Durum |
|-------|-------|-------|
| SSH — Satış Sonrası Hizmet | [`ssh.md`](./ssh.md) | 🔜 Planlandı (henüz başlanmadı) |

> Bir modül geliştirilmeye başlanınca dosyası [`../`](../) (mevcut modüller)
> altına taşınır ve durumu ✅ Mevcut olur.
